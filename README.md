# Trasteros

Juego de subastas de trasteros a ciegas para jugar con amigos desde el móvil:
**https://gkilian007.github.io/trasteros/**

Este repositorio solo contiene el juego ya montado (carpeta `docs/`), tal como lo descarga el navegador,
y la tarea diaria que actualiza los cupones de descuento (`tools/coupons/fetch.mjs`).
El código fuente se mantiene en un repositorio privado.
